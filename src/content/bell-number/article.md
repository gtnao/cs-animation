## ベル数とは

ベル数 $B_n$ は、$n$ 個の要素の集合を任意の数の空でない部分集合に分割する方法の総数である。

最初のいくつかの値:

$$
B_0 = 1, \quad B_1 = 1, \quad B_2 = 2, \quad B_3 = 5, \quad B_4 = 15, \quad B_5 = 52
$$

## 定義

### スターリング数による定義

$$
B_n = \sum_{k=0}^{n} S(n, k)
$$

ここで $S(n, k)$ は第二種スターリング数である。

### 漸化式

$$
B_{n+1} = \sum_{k=0}^{n} \binom{n}{k} B_k
$$

### 直感的な理解

$B_{n+1}$ の漸化式を理解するには、要素 $n+1$ がどの部分集合に入るかで場合分けする。要素 $n+1$ と一緒にグループを形成する要素の集合を $S$ とする。$|S| = k$ のとき、残りの $n - k$ 個の要素の分割方法は $B_{n-k}$ 通り、$S$ の選び方は $\binom{n}{k}$ 通りである。$k = 0, 1, \ldots, n$ について足し上げると漸化式が得られる。

## ベル三角形

ベル数を効率的に計算する方法として **ベル三角形** (Bell triangle, Aitken's array) がある。

### 構築規則

1. $T(0, 0) = 1$
2. 各行 $i$ の先頭 $T(i, 0)$ は前行の末尾 $T(i-1, i-1)$
3. それ以外: $T(i, j) = T(i, j-1) + T(i-1, j-1)$

### ベル三角形の例

| | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 0 | **1** | | | | |
| 1 | **1** | 2 | | | |
| 2 | **2** | 3 | 5 | | |
| 3 | **5** | 7 | 10 | 15 | |
| 4 | **15** | 20 | 27 | 37 | 52 |

各行の先頭 (太字) がベル数: $B_0 = 1, B_1 = 1, B_2 = 2, B_3 = 5, B_4 = 15$

## 実装

### ベル三角形による計算

```python title="bell_triangle.py"
def bell_numbers(n: int) -> list[int]:
    """Compute B(0), B(1), ..., B(n) using Bell triangle"""
    if n == 0:
        return [1]

    triangle = [[0] * (i + 1) for i in range(n + 1)]
    triangle[0][0] = 1

    for i in range(1, n + 1):
        triangle[i][0] = triangle[i-1][i-1]
        for j in range(1, i + 1):
            triangle[i][j] = triangle[i][j-1] + triangle[i-1][j-1]

    return [triangle[i][0] for i in range(n + 1)]
```

### 明示公式 (Dobinski の公式)

$$
B_n = \frac{1}{e} \sum_{k=0}^{\infty} \frac{k^n}{k!}
$$

この無限級数は急速に収束するため、有限項で近似できる。ただしモジュラ算術が必要な場面では使いにくい。

## 計算量

| 方法 | 時間計算量 | 空間計算量 |
|------|-----------|-----------|
| ベル三角形 | $O(n^2)$ | $O(n^2)$ |
| ベル三角形 (空間最適化) | $O(n^2)$ | $O(n)$ |
| 漸化式 + 二項係数 | $O(n^2)$ | $O(n)$ |

## ベル数の指数的母関数

$$
\sum_{n=0}^{\infty} B_n \frac{x^n}{n!} = e^{e^x - 1}
$$

## ベル数の性質

### 漸近的な振る舞い

ベル数は超指数的に増大する:

$$
\ln B_n \sim n \ln n - n \ln \ln n - n
$$

### mod p での周期性

$p$ が素数のとき、ベル数の列は $\bmod p$ で周期 $p^p - 1$ の周期を持つことが知られている (Touchard の定理の一般化)。

### Touchard の合同式

$p$ が素数のとき:

$$
B_{n+p} \equiv B_n + B_{n+1} \pmod{p}
$$

## 応用

- 集合の分割の数え上げ
- 等価関係の数
- グラフの頂点彩色 (色の区別なし)
- 関数の等価類の数
