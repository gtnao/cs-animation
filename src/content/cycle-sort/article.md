## Cycle Sort とは

Cycle Sort (サイクルソート) は、**書き込み回数を理論的最小に抑える** in-place のソートアルゴリズムである。各要素を最終的な正しい位置に直接配置することで、不要な書き込みを一切行わない。

## アルゴリズムの概要

### 核心アイデア：置換のサイクル分解

配列のソートは、元の配列からソート済み配列への**置換** (permutation) と見なせる。任意の置換はいくつかの**サイクル**に分解できる。

例えば `[4, 3, 1, 2]` をソートする置換は:
- $1 \to 3 \to 2 \to 4 \to 1$ (1 つのサイクル)

サイクル内の要素を順に正しい位置に配置していけば、最小回数の書き込みでソートが完了する。

### 手順

各位置 $i$ について:
1. $a[i]$ の正しい位置 $pos$ を計算する ($a[i]$ より小さい要素の数を数える)
2. $a[i]$ が既に正しい位置にあれば次へ
3. $a[i]$ を位置 $pos$ に配置し、元あった値を取り出す
4. 取り出した値の正しい位置を計算し、配置する
5. サイクルの開始位置に戻るまで繰り返す

### 具体例

配列 `[4, 3, 1, 2]` をソートする:

**サイクル開始: 位置 0, item = 4**
1. 4 より小さい要素: 3個 → 正しい位置は 3
2. 位置 3 に 4 を配置、2 を取り出す → `[4, 3, 1, 4]`, item = 2
3. 2 より小さい要素: 1個 → 正しい位置は 1
4. 位置 1 に 2 を配置、3 を取り出す → `[4, 2, 1, 4]`, item = 3
5. 3 より小さい要素: 2個 → 正しい位置は 2
6. 位置 2 に 3 を配置、1 を取り出す → `[4, 2, 3, 4]`, item = 1
7. 1 より小さい要素: 0個 → 正しい位置は 0 = サイクル開始
8. 位置 0 に 1 を配置 → `[1, 2, 3, 4]`

## 実装

```python title="cycle_sort.py"
def cycle_sort(a: list[int]) -> list[int]:
    n = len(a)
    writes = 0

    for cycle_start in range(n - 1):
        item = a[cycle_start]

        # Find the correct position for item
        pos = cycle_start
        for i in range(cycle_start + 1, n):
            if a[i] < item:
                pos += 1

        # Skip if already in place
        if pos == cycle_start:
            continue

        # Handle duplicates
        while item == a[pos]:
            pos += 1

        # Place item
        a[pos], item = item, a[pos]
        writes += 1

        # Rotate the rest of the cycle
        while pos != cycle_start:
            pos = cycle_start
            for i in range(cycle_start + 1, n):
                if a[i] < item:
                    pos += 1
            while item == a[pos]:
                pos += 1
            if item != a[pos]:
                a[pos], item = item, a[pos]
                writes += 1

    return a
```

## 計算量

| ケース | 時間計算量 | 説明 |
|--------|-----------|------|
| 最良 | $O(n^2)$ | |
| 平均 | $O(n^2)$ | |
| 最悪 | $O(n^2)$ | |

**空間計算量:** $O(1)$ (in-place)

### 書き込み回数

Cycle Sort の最大の特徴は、**書き込み回数が理論的最小**であることである。各要素は最大 1 回だけ書き込まれる。

書き込み回数は $n - c$ に等しい。ここで $c$ は置換のサイクル数である。これは任意の in-place ソートにおける書き込み回数の下界と一致する。

## 安定性

Cycle Sort は**不安定ソート**である。重複要素がある場合の配置処理により、等しい要素の相対順序が変わる可能性がある。

## 書き込み回数の最適性

### 命題: Cycle Sort の書き込み回数は最小

**証明:**

ソートを置換 $\pi$ と見なす。$\pi$ は互いに素なサイクルに分解される。サイクル数を $c$ とする。

長さ $k$ のサイクルを完了するには $k$ 回の書き込みが必要 (各要素を 1 回ずつ正しい位置に配置)。ただし、サイクルの最後の書き込みで開始位置の要素も確定するため、実質的には $k$ 回の書き込みである。

全サイクルの要素数の合計は $n$ であり、既に正しい位置にある要素 (長さ 1 のサイクル) は書き込み不要なので、書き込み回数は $n - c$ である。

これは理論的下界に一致する。 $\square$

## 特徴と応用

### 長所

- 書き込み回数が理論的最小
- in-place (追加メモリ $O(1)$)
- Flash メモリなど書き込みコストが高い場合に有利

### 短所

- 時間計算量が $O(n^2)$
- 不安定ソート
- 読み取り回数が多い

### 応用場面

- Flash メモリ、EEPROM など書き込み回数に制限があるデバイス
- 書き込みコストが高いストレージ
- 理論的な置換研究
