## Bubble Sort とは

Bubble Sort (バブルソート) は、隣接する要素を繰り返し比較・交換することで配列を整列するソートアルゴリズムである。大きな要素が泡 (bubble) のように配列の末尾へ浮き上がっていく様子からこの名前がついた。

## アルゴリズムの概要

### 基本的な考え方

配列の先頭から末尾に向かって隣接する 2 要素を比較し、順序が逆なら交換する。この操作を 1 パスとして繰り返すと、各パスの終了後に未整列部分の最大値が正しい位置に確定する。

### 具体例

配列 `[5, 3, 8, 1, 2]` をソートする過程:

**パス 1:**
- `[5, 3, 8, 1, 2]` → 5 > 3 なので交換 → `[3, 5, 8, 1, 2]`
- `[3, 5, 8, 1, 2]` → 5 ≤ 8 なので交換なし
- `[3, 5, 8, 1, 2]` → 8 > 1 なので交換 → `[3, 5, 1, 8, 2]`
- `[3, 5, 1, 8, 2]` → 8 > 2 なので交換 → `[3, 5, 1, 2, 8]`
- **8 が確定**

**パス 2:**
- `[3, 5, 1, 2, 8]` → 3 ≤ 5 なので交換なし
- `[3, 5, 1, 2, 8]` → 5 > 1 なので交換 → `[3, 1, 5, 2, 8]`
- `[3, 1, 5, 2, 8]` → 5 > 2 なので交換 → `[3, 1, 2, 5, 8]`
- **5 が確定**

以降同様に繰り返し、`[1, 2, 3, 5, 8]` が得られる。

## 実装

```python title="bubble_sort.py"
def bubble_sort(a: list[int]) -> list[int]:
    n = len(a)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        # Early termination: if no swaps occurred, array is sorted
        if not swapped:
            break
    return a
```

### 早期終了の最適化

あるパスで一度も交換が発生しなかった場合、配列は既に整列されている。この条件を検出して早期に終了することで、最良ケースの計算量を $O(n)$ に改善できる。

## 計算量

| ケース | 時間計算量 | 説明 |
|--------|-----------|------|
| 最良 | $O(n)$ | 既にソート済み (早期終了あり) |
| 平均 | $O(n^2)$ | ランダムな入力 |
| 最悪 | $O(n^2)$ | 逆順にソート済み |

**空間計算量:** $O(1)$ (in-place)

### 計算量の導出

パス $i$ ($0$-indexed) では $n - 1 - i$ 回の比較を行う。全パスの比較回数の合計は:

$$
\sum_{i=0}^{n-2} (n - 1 - i) = \frac{n(n-1)}{2} = O(n^2)
$$

## 正当性の証明

### ループ不変条件

パス $i$ の終了時に、配列の末尾 $i + 1$ 個の要素は最終的な正しい位置にある。

**初期条件:** パス 0 の前、確定した要素は 0 個。自明に成立。

**維持:** パス $i$ では、未整列部分の最大値が隣接交換により末尾に移動する。したがって、パス $i$ の終了後、末尾 $i + 1$ 個が確定する。

**終了条件:** $n - 1$ パス後、全要素が正しい位置にある。

## 安定性

Bubble Sort は**安定ソート**である。等しい要素の比較では交換を行わない ($a[j] > a[j+1]$ の場合のみ交換) ため、等しい要素の相対順序は保存される。

## 特徴と応用

### 長所

- 実装が非常に簡単
- 安定ソート
- in-place (追加メモリ $O(1)$)
- ほぼソート済みのデータに対しては効率的 (早期終了により $O(n)$)

### 短所

- 平均・最悪計算量が $O(n^2)$ で大規模データには不向き
- 比較回数・交換回数ともに多い

### 応用場面

- 教育目的でのソートアルゴリズムの導入
- データ量が非常に少ない場合
- ほぼ整列済みのデータの微調整
