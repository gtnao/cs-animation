## Booth のアルゴリズムとは

Booth のアルゴリズムは、文字列 $S$ の**辞書順最小の巡回シフト (最小回転)** を $O(n)$ 時間、$O(n)$ 空間で求めるアルゴリズムである。1980年に Kellogg S. Booth によって発表された。

### 巡回シフト

文字列 $S = s_0 s_1 \cdots s_{n-1}$ の位置 $k$ からの巡回シフトは以下の文字列である。

$$
\text{rot}(S, k) = s_k s_{k+1} \cdots s_{n-1} s_0 s_1 \cdots s_{k-1}
$$

$n$ 個の巡回シフトのうち、辞書順で最小のものを求めるのが目標である。

### 具体例

文字列 `cab` の巡回シフト:

- $\text{rot}(0)$ = `cab`
- $\text{rot}(1)$ = `abc`
- $\text{rot}(2)$ = `bca`

最小巡回シフトは $\text{rot}(1)$ = `abc`。

## 素朴な方法

全 $n$ 個の巡回シフトを生成してソートすれば $O(n^2 \log n)$ で求められるが、非効率である。

## Booth のアルゴリズム

### 核心アイデア

文字列 $S$ を2回連結した $S' = SS$ に対して、KMP法に似た失敗関数を改良して適用する。

$S'$ の長さ $n$ の部分文字列は $S$ の巡回シフトに対応する。したがって $S'$ 上で辞書順最小の長さ $n$ の部分文字列の開始位置を求めればよい。

### 実装

```python title="booth.py"
def min_rotation(s: str) -> int:
    n = len(s)
    s2 = s + s
    f = [-1] * (2 * n)
    k = 0  # current best starting position

    for j in range(1, 2 * n):
        i = f[j - 1 - k]
        while i != -1 and s2[j] != s2[k + i + 1]:
            if s2[j] < s2[k + i + 1]:
                k = j - i - 1
            i = f[i]
        if s2[j] != s2[k + i + 1]:
            if s2[j] < s2[k + i + 1]:
                k = j
            f[j - k] = -1
        else:
            f[j - k] = i + 1

    return k
```

## 計算量

### 命題: Booth のアルゴリズムは $O(n)$

**証明の概要:**

アルゴリズムは KMP 法の失敗関数の構築と同様の構造を持つ。外側のループは $2n$ 回であり、内側の while ループはポテンシャル論法で合計 $O(n)$ 回しか回らない。

## Lyndon 分解との関係

Lyndon 分解を使って最小巡回シフトを求めることもできる。

文字列 $S$ を2回連結した $SS$ の Lyndon 分解を考えると、最小巡回シフトの開始位置は最後のLyndon語から特定できる。

## 応用

1. **文字列の正規形:** 巡回シフトの等価クラスを代表元 (最小回転) で統一的に扱う
2. **化学の分子構造:** 環状分子の標準表現
3. **ネックレス問題:** 組合せ論におけるネックレスの辞書順最小表現
4. **データ圧縮:** BWT で番兵文字なしに最小回転を利用

## まとめ

| 項目 | 内容 |
|------|------|
| 入力 | 長さ $n$ の文字列 $S$ |
| 出力 | 辞書順最小の巡回シフトの開始位置 |
| 時間計算量 | $O(n)$ |
| 空間計算量 | $O(n)$ |
| 核心 | 2回連結 + 改良失敗関数 |
