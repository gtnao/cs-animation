## Shell Sort とは

Shell Sort (シェルソート) は、Donald Shell が 1959 年に提案したソートアルゴリズムである。挿入ソートの一般化であり、離れた要素同士を比較・交換することで、挿入ソートの弱点である「要素が遠い位置に移動するのに時間がかかる」問題を改善する。

## アルゴリズムの概要

### 基本的な考え方

1. 大きなギャップ (間隔) から始め、ギャップ間隔で離れた要素に対して挿入ソートを行う
2. ギャップを徐々に縮小する
3. 最終的にギャップ = 1 で通常の挿入ソートを行う

ギャップが大きいときに大まかに整列させることで、ギャップが小さくなった時にはほぼ整列済みの状態になり、挿入ソートが高速に動作する。

### 具体例

配列 `[8, 3, 5, 1, 4, 2, 6, 7]` をギャップ列 `[4, 2, 1]` でソートする:

**ギャップ = 4:**
- 位置 0,4 のグループ: [8,4] → [4,8]
- 位置 1,5 のグループ: [3,2] → [2,3]
- 位置 2,6 のグループ: [5,6] → [5,6]
- 位置 3,7 のグループ: [1,7] → [1,7]
- 結果: `[4, 2, 5, 1, 8, 3, 6, 7]`

**ギャップ = 2:**
- 各グループを挿入ソート
- 結果: `[4, 1, 5, 2, 6, 3, 8, 7]`

**ギャップ = 1:**
- 通常の挿入ソート (ほぼ整列済みなので高速)
- 結果: `[1, 2, 3, 4, 5, 6, 7, 8]`

## 実装

```python title="shell_sort.py"
def shell_sort(a: list[int]) -> list[int]:
    n = len(a)
    gap = n // 2

    while gap > 0:
        for i in range(gap, n):
            key = a[i]
            j = i - gap
            while j >= 0 and a[j] > key:
                a[j + gap] = a[j]
                j -= gap
            a[j + gap] = key
        gap //= 2

    return a
```

## ギャップ列

Shell Sort の性能はギャップ列の選択に大きく依存する。

### 代表的なギャップ列

| ギャップ列 | 定義 | 最悪計算量 |
|-----------|------|-----------|
| Shell (1959) | $n/2, n/4, \ldots, 1$ | $O(n^2)$ |
| Hibbard (1963) | $2^k - 1$: 1, 3, 7, 15, ... | $O(n^{3/2})$ |
| Knuth (1973) | $(3^k - 1)/2$: 1, 4, 13, 40, ... | $O(n^{3/2})$ |
| Sedgewick (1986) | $4^k + 3 \cdot 2^{k-1} + 1$ | $O(n^{4/3})$ |
| Tokuda (1992) | $\lceil(9 \cdot (9/4)^k - 4) / 5\rceil$ | 未証明だが実用上高速 |

### Shell のギャップ列の問題点

Shell の元々のギャップ列 $n/2, n/4, \ldots$ は最悪 $O(n^2)$ になる。これは偶数位置の要素と奇数位置の要素がギャップ = 1 まで比較されないことが原因である。

## 計算量

| ケース | 時間計算量 | 説明 |
|--------|-----------|------|
| 最良 | $O(n \log n)$ | ほぼソート済み |
| 平均 | ギャップ列に依存 | |
| 最悪 | $O(n^2)$ (Shell), $O(n^{3/2})$ (Hibbard) | ギャップ列に依存 |

**空間計算量:** $O(1)$ (in-place)

## 安定性

Shell Sort は**不安定ソート**である。離れた位置の要素を交換するため、等しい要素の相対順序が変わる可能性がある。

## 特徴と応用

### 長所

- 実装が比較的簡単
- in-place (追加メモリ $O(1)$)
- 適切なギャップ列で $O(n^{3/2})$ 以下を達成
- 挿入ソートよりも大幅に高速

### 短所

- 最適なギャップ列が未解決問題
- 不安定ソート
- Quick Sort や Merge Sort には及ばないことが多い

### 応用場面

- 組み込みシステム (メモリ制約が厳しい環境)
- 中規模データのソート
- Insertion Sort を高速化したい場合

| 安定性 | 不安定 |
