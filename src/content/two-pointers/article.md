## しゃくとり法とは

しゃくとり法 (Two Pointers / 尺取り法) は、配列上の2つのポインタ $l, r$ を管理し、条件を満たす区間 $[l, r)$ を効率的に列挙する手法である。

### 適用条件

$r$ を増やすと条件が「緩く」なり、$l$ を増やすと条件が「厳しく」なるような単調性がある場合に適用できる。

## アルゴリズム

典型的な問題: 配列 $A$ の連続部分配列で、合計が $S$ 以上となる最短のものを求める。

```python title="two_pointers.py"
def min_subarray_sum(a: list[int], s: int) -> int:
    n = len(a)
    ans = n + 1
    total = 0
    left = 0
    for right in range(n):
        total += a[right]
        while total >= s:
            ans = min(ans, right - left + 1)
            total -= a[left]
            left += 1
    return ans if ans <= n else -1
```

## 計算量

各ポインタは $0$ から $n$ まで単調に増加するため、全体で $O(n)$ である。

$$
T(n) = O(n)
$$

### 正当性

$l$ を固定したとき、条件を満たす最小の $r$ を $r(l)$ とすると、$l$ が増加すると $r(l)$ も増加する (単調性)。これにより、$l$ と $r$ をそれぞれ高々 $n$ 回しか動かさない。

## 応用

- **最長/最短の条件付き区間**: 合計が閾値以下/以上の区間
- **文字の種類数が $k$ 以下の最長部分文字列**
- **重複なしの最長部分文字列**

## まとめ

| 項目 | 内容 |
|------|------|
| 入力 | 長さ $n$ の配列、条件 |
| 出力 | 条件を満たす区間の最適解 |
| 時間計算量 | $O(n)$ |
| 空間計算量 | $O(1)$ (追加) |
| 前提 | 区間に対する条件の単調性 |
