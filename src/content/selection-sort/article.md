## Selection Sort とは

Selection Sort (選択ソート) は、未整列部分から最小 (または最大) の要素を見つけ出し、未整列部分の先頭と交換することで配列を整列するソートアルゴリズムである。

## アルゴリズムの概要

### 手順

1. 配列の未整列部分から最小値を見つける
2. 最小値を未整列部分の先頭と交換する
3. 整列済み部分を 1 つ拡大する
4. 未整列部分がなくなるまで繰り返す

### 具体例

配列 `[5, 3, 8, 1, 2]` をソートする:

| パス | 最小値 | 交換 | 結果 |
|------|--------|------|------|
| 1 | 1 (位置3) | 5 ↔ 1 | `[1, 3, 8, 5, 2]` |
| 2 | 2 (位置4) | 3 ↔ 2 | `[1, 2, 8, 5, 3]` |
| 3 | 3 (位置4) | 8 ↔ 3 | `[1, 2, 3, 5, 8]` |
| 4 | 5 (位置3) | 交換なし | `[1, 2, 3, 5, 8]` |

## 実装

```python title="selection_sort.py"
def selection_sort(a: list[int]) -> list[int]:
    n = len(a)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if a[j] < a[min_idx]:
                min_idx = j
        if min_idx != i:
            a[i], a[min_idx] = a[min_idx], a[i]
    return a
```

## 計算量

| ケース | 時間計算量 | 説明 |
|--------|-----------|------|
| 最良 | $O(n^2)$ | 比較回数は入力に依存しない |
| 平均 | $O(n^2)$ | |
| 最悪 | $O(n^2)$ | |

**空間計算量:** $O(1)$ (in-place)

### 計算量の導出

パス $i$ ($0$-indexed) では $n - 1 - i$ 回の比較を行う。比較回数の合計は入力の内容によらず一定で:

$$
\sum_{i=0}^{n-2} (n - 1 - i) = \frac{n(n-1)}{2} = O(n^2)
$$

一方、交換回数は高々 $n - 1$ 回であり、$O(n)$ である。これは Bubble Sort に比べて交換回数が少ない利点である。

## 正当性の証明

### ループ不変条件

パス $i$ の終了時に、$a[0], a[1], \ldots, a[i]$ は最終的なソート結果の先頭 $i + 1$ 個と一致し、正しい位置にある。

**初期条件:** パス 0 の前、確定した要素は 0 個。自明に成立。

**維持:** パス $i$ では、$a[i], a[i+1], \ldots, a[n-1]$ の中から最小値を選び $a[i]$ と交換する。$a[0..i-1]$ は既にソート済みであり全て $a[i]$ 以下であるから、$a[0..i]$ はソート結果の先頭 $i + 1$ 個と一致する。

**終了条件:** $n - 1$ パス後、全要素が正しい位置にある。

## 安定性

Selection Sort は**不安定ソート**である。例えば `[3a, 3b, 1]` をソートすると:
- パス 1: 最小値 1 (位置2) と 3a (位置0) を交換 → `[1, 3b, 3a]`
- 3a と 3b の相対順序が逆転している

## 特徴と応用

### 長所

- 実装が簡単
- 交換回数が最大 $O(n)$ で少ない (書き込みコストが高い場合に有利)
- in-place

### 短所

- 比較回数が常に $O(n^2)$ で、入力に関わらず高速化しない
- 不安定ソート

### 応用場面

- メモリへの書き込みが高コストな場合 (Flash memory 等)
- 教育目的

## まとめ

| 項目 | 内容 |
|------|------|
| 時間計算量 (最良/平均/最悪) | $O(n^2)$ / $O(n^2)$ / $O(n^2)$ |
| 空間計算量 | $O(1)$ |
| 安定性 | 不安定 |
| in-place | はい |
| 手法 | 最小値選択と交換 |
