## Insertion Sort とは

Insertion Sort (挿入ソート) は、配列の要素を 1 つずつ取り出し、既に整列済みの部分の正しい位置に挿入することで配列全体を整列するソートアルゴリズムである。トランプの手札を並べ替えるときの手法に似ている。

## アルゴリズムの概要

### 手順

1. 配列の 2 番目の要素から順に取り出す (key)
2. key を整列済み部分の正しい位置に挿入する
3. 挿入位置より右の要素を 1 つずつ右にシフトする
4. 全要素を処理するまで繰り返す

### 具体例

配列 `[5, 3, 8, 1, 2]` をソートする:

| ステップ | key | 操作 | 結果 |
|----------|-----|------|------|
| 1 | 3 | 5を右にシフト、3を位置0に挿入 | `[3, 5, 8, 1, 2]` |
| 2 | 8 | 8 ≥ 5 なので移動なし | `[3, 5, 8, 1, 2]` |
| 3 | 1 | 8,5,3を右にシフト、1を位置0に挿入 | `[1, 3, 5, 8, 2]` |
| 4 | 2 | 8,5,3を右にシフト、2を位置1に挿入 | `[1, 2, 3, 5, 8]` |

## 実装

```python title="insertion_sort.py"
def insertion_sort(a: list[int]) -> list[int]:
    n = len(a)
    for i in range(1, n):
        key = a[i]
        j = i - 1
        # Shift elements greater than key to the right
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a
```

## 計算量

| ケース | 時間計算量 | 説明 |
|--------|-----------|------|
| 最良 | $O(n)$ | 既にソート済み |
| 平均 | $O(n^2)$ | ランダムな入力 |
| 最悪 | $O(n^2)$ | 逆順にソート済み |

**空間計算量:** $O(1)$ (in-place)

### 最良ケースの分析

配列が既にソート済みの場合、内側の while ループは一度も実行されない。外側のループが $n - 1$ 回実行されるだけなので、$O(n)$ となる。

### 最悪ケースの分析

配列が逆順の場合、要素 $a[i]$ を挿入するために $i$ 回のシフトが必要になる。合計シフト回数は:

$$
\sum_{i=1}^{n-1} i = \frac{n(n-1)}{2} = O(n^2)
$$

### 平均ケースの分析

ランダムな配列では、要素 $a[i]$ の挿入位置は平均して整列済み部分の中央付近になる。平均シフト回数は $i/2$ であるから:

$$
\sum_{i=1}^{n-1} \frac{i}{2} = \frac{n(n-1)}{4} = O(n^2)
$$

## 正当性の証明

### ループ不変条件

外側のループの各反復の開始時に、部分配列 $a[0..i-1]$ は元の $a[0..i-1]$ の要素がソートされた状態になっている。

**初期条件:** $i = 1$ のとき、$a[0..0]$ は要素 1 つで自明にソート済み。

**維持:** 内側の while ループで $a[i]$ より大きい要素を右にシフトし、正しい位置に $a[i]$ を挿入する。これにより $a[0..i]$ がソート済みになる。

**終了条件:** $i = n$ でループ終了。$a[0..n-1]$ 全体がソート済み。

## 安定性

Insertion Sort は**安定ソート**である。等しい要素に対しては ($a[j] > key$ の条件により) シフトが行われないため、等しい要素の相対順序は保存される。

## 特徴と応用

### 長所

- 実装が簡単
- 安定ソート
- in-place
- ほぼソート済みのデータに対して非常に高速 ($O(n)$)
- オンラインアルゴリズム (データが逐次到着しても処理可能)
- 小規模データではオーバーヘッドが少なく高速

### 短所

- 平均・最悪計算量が $O(n^2)$

### 応用場面

- 小規模データのソート
- ほぼ整列済みデータのソート
- Tim Sort や Intro Sort のサブルーチンとして
- オンラインでのデータ挿入

## まとめ

| 項目 | 内容 |

| 時間計算量 (最良/平均/最悪) | $O(n)$ / $O(n^2)$ / $O(n^2)$ |
| 空間計算量 | $O(1)$ |
| 安定性 | 安定 |
| in-place | はい |
| 手法 | 整列済み部分への挿入 |
