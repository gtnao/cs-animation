## KMP法とは

KMP法 (Knuth-Morris-Pratt Algorithm) は、テキスト $T$ の中からパターン $P$ の出現位置を効率的に見つける文字列検索アルゴリズムである。1977年に Knuth, Morris, Pratt によって発表された。

素朴なパターンマッチングが最悪 $O(nm)$ かかるのに対し、KMP法は**失敗関数 (failure function)** を前計算することで $O(n + m)$ で検索を完了する。

### 問題設定

- テキスト $T = t_0 t_1 \cdots t_{n-1}$ (長さ $n$)
- パターン $P = p_0 p_1 \cdots p_{m-1}$ (長さ $m$)
- $T$ の中で $P$ が出現する全ての位置を求める

## 失敗関数 (Failure Function)

### 定義

パターン $P$ の**失敗関数** (prefix function とも呼ばれる) $\pi[0..m-1]$ を次のように定義する。

$$
\pi[q] = \max\{\ k \mid 0 \leq k < q,\ P[0..k-1] = P[q-k+1..q]\ \}
$$

すなわち、$\pi[q]$ は $P[0..q]$ の**真の接頭辞**であり同時に**接尾辞**でもある最長の文字列の長さである。

### 具体例

パターン `ababcabab` の失敗関数を求める。

| $q$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|-----|---|---|---|---|---|---|---|---|---|
| $P[q]$ | a | b | a | b | c | a | b | a | b |
| $\pi[q]$ | 0 | 0 | 1 | 2 | 0 | 1 | 2 | 3 | 4 |

- $\pi[3] = 2$: `abab` の真の接頭辞かつ接尾辞の最長は `ab` (長さ2)
- $\pi[8] = 4$: `ababcabab` の真の接頭辞かつ接尾辞の最長は `abab` (長さ4)

### 失敗関数の構築

失敗関数は KMP 検索アルゴリズム自身と同様の考え方で $O(m)$ で構築できる。

```python title="build_failure.py"
def build_failure(pattern: str) -> list[int]:
    m = len(pattern)
    pi = [0] * m
    k = 0
    for q in range(1, m):
        while k > 0 and pattern[k] != pattern[q]:
            k = pi[k - 1]
        if pattern[k] == pattern[q]:
            k += 1
        pi[q] = k
    return pi
```

## 検索アルゴリズム

### 核心アイデア

KMP法の核心は、不一致が起きたとき**パターンの先頭に戻るのではなく、失敗関数を利用して適切な位置まで戻る**ことで、テキストの再走査を避ける点にある。

不一致が位置 $j$ で起きた場合、$P[0..j-1]$ はすでにテキストと一致している。この一致済み部分の接頭辞かつ接尾辞の最長部分 ($\pi[j-1]$ 文字) は次の照合でも一致が保証されるため、$j$ を $\pi[j-1]$ に設定して比較を続けられる。

### 実装

```python title="kmp_search.py"
def kmp_search(text: str, pattern: str) -> list[int]:
    n, m = len(text), len(pattern)
    pi = build_failure(pattern)
    result = []
    j = 0  # number of characters matched
    for i in range(n):
        while j > 0 and pattern[j] != text[i]:
            j = pi[j - 1]
        if pattern[j] == text[i]:
            j += 1
        if j == m:
            result.append(i - m + 1)
            j = pi[j - 1]
    return result
```

### 動作例

テキスト `ababcababababcabab`、パターン `ababcabab` で検索する。

位置 0 から照合を開始し、`ababcabab` が一致して位置 0 で発見される。このとき $j = \pi[8] = 4$ にフォールバックし、次の照合は `abab` の一致を再利用して位置 4 から効率的に続行される。

## 計算量の証明

### 命題: KMP法の時間計算量は $O(n + m)$

**証明:**

失敗関数の構築は $O(m)$ である (Z-Algorithm と同様のポテンシャル論法による)。

検索フェーズを分析する。ポテンシャル関数 $\Phi = j$ (現在のパターン中の位置) を考える。

- `if pattern[j] == text[i]`: $j$ が 1 増加し、$i$ も 1 増加する。この操作は $n$ 回を超えない
- `while j > 0 and ...`: $j$ が減少する。$j$ の増加量は全体で高々 $n$ なので、減少の総量も高々 $n$

したがって while ループの総反復回数は $O(n)$。全体として検索フェーズは $O(n)$。

構築と検索を合わせて $O(n + m)$。 $\square$

## KMP法の正当性

### なぜフォールバックで正解を見逃さないか

不一致が $P[j]$ で発生したとする。このとき $T[i-j..i-1] = P[0..j-1]$ である。

$\pi[j-1] = k$ とすると、$P[0..k-1] = P[j-k..j-1]$ である。つまり $T[i-k..i-1] = P[0..k-1]$ が保証される。

$P[0..j-1]$ の真の接頭辞かつ接尾辞で $k$ より長いものは存在しない ($\pi$ の最大性)。したがって、フォールバック先を $k$ 以外にすると、接頭辞の一致が短くなるか0になるだけで、パターンの出現を見逃すことはない。

## Z-Algorithm との関係

Z-Algorithm と KMP法は、ともに線形時間の文字列検索アルゴリズムであり、同じ問題クラスに適用できる。

- Z-Algorithm は $S$ と各接尾辞の**最長共通接頭辞**を計算する
- KMP法は各接頭辞の**最長の真の接頭辞兼接尾辞**を計算する

両者は相互に変換可能であり、本質的に等価な情報を異なる視点から捉えている。

## 応用

1. **文字列検索**: テキスト中のパターン出現位置の検出
2. **文字列の周期**: $\pi$ 配列から文字列の最小周期を $O(n)$ で求められる。$P$ の最小周期は $m - \pi[m-1]$
3. **KMP オートマトン**: 失敗関数をオートマトンとして構築することで、複数テキストに対する検索を効率化
