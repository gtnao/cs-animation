## 概要

**高速ゼータ変換** と **高速メビウス変換** は、集合関数 (集合を引数にとる関数) に対する変換を $O(2^n \cdot n)$ で計算するアルゴリズムである。素朴に計算すると $O(3^n)$ かかるところを大幅に高速化する。

## 定義

### 集合関数

$n$ 要素の集合 $U = \{0, 1, \ldots, n-1\}$ の部分集合全体 $2^U$ 上の関数 $f: 2^U \to \mathbb{R}$ を考える。部分集合をビットマスクで表現し、$f(S)$ を配列 $f[S]$ として扱う。

### 下位集合ゼータ変換

$$
\hat{f}(S) = \sum_{T \subseteq S} f(T)
$$

$S$ の全ての部分集合 $T$ について $f(T)$ を合計する。

### 上位集合ゼータ変換

$$
\hat{f}(S) = \sum_{S \subseteq T} f(T)
$$

$S$ を含む全ての上位集合 $T$ について $f(T)$ を合計する。

### メビウス変換

ゼータ変換の逆変換である。

$$
f(S) = \sum_{T \subseteq S} (-1)^{|S \setminus T|} \hat{f}(T)
$$

## 素朴なアプローチ

全ての $(S, T)$ のペアを列挙して計算すると $O(3^n)$ である ($S$ の部分集合を列挙する際の合計が $\sum_{S} 2^{|S|} = 3^n$)。

## 高速ゼータ変換

### 核心アイデア

各ビットを 1 つずつ処理する。ビット $i$ について、$S$ がビット $i$ を含む場合、$S$ からビット $i$ を除いた集合の値を加算する。

### 下位集合ゼータ変換のアルゴリズム

```python title="zeta_sub.py"
def zeta_subset(f, n):
    """f[S] = sum_{T subseteq S} f[T]"""
    for i in range(n):
        for s in range(1 << n):
            if s & (1 << i):
                f[s] += f[s ^ (1 << i)]
```

### 正当性

ビット $i$ の処理後、$f[S]$ には「ビット $0, 1, \ldots, i$ に関して $S$ の部分集合」からの寄与が含まれている。全ビットを処理し終えると、$f[S]$ には $S$ の全ての部分集合からの寄与が含まれる。

**帰納法による証明:**

ビット $0, 1, \ldots, i-1$ の処理後、$f[S]$ は「ビット $0, \ldots, i-1$ について部分集合の和」を保持していると仮定する。ビット $i$ の処理で:

- $S$ がビット $i$ を持つ場合: $f[S]$ に $f[S \setminus \{i\}]$ を加算する。$f[S \setminus \{i\}]$ はビット $i$ を含まない部分集合の和を既に持っているので、これで「ビット $i$ を含む/含まない」両方の部分集合をカバーする。
- $S$ がビット $i$ を持たない場合: 何もしない (ビット $i$ に関する部分集合は自身のみ)。

### 上位集合ゼータ変換

```python title="zeta_super.py"
def zeta_superset(f, n):
    """f[S] = sum_{S subseteq T} f[T]"""
    for i in range(n):
        for s in range(1 << n):
            if not (s & (1 << i)):
                f[s] += f[s | (1 << i)]
```

### メビウス変換 (逆変換)

ゼータ変換の逆演算。加算を減算に変えるだけでよい。

```python title="mobius.py"
def mobius_subset(f, n):
    """下位集合メビウス変換 (下位集合ゼータの逆)"""
    for i in range(n):
        for s in range(1 << n):
            if s & (1 << i):
                f[s] -= f[s ^ (1 << i)]

def mobius_superset(f, n):
    """上位集合メビウス変換 (上位集合ゼータの逆)"""
    for i in range(n):
        for s in range(1 << n):
            if not (s & (1 << i)):
                f[s] -= f[s | (1 << i)]
```

## 計算量

| 手法 | 時間計算量 | 空間計算量 |
|------|-----------|-----------|
| 素朴 | $O(3^n)$ | $O(2^n)$ |
| 高速変換 | $O(2^n \cdot n)$ | $O(2^n)$ |

## 応用

### OR畳み込み

2 つの集合関数 $f, g$ の OR 畳み込み (union convolution)

$$
h(S) = \sum_{T_1 \cup T_2 = S} f(T_1) \cdot g(T_2)
$$

は下位集合ゼータ変換を用いて計算できる。

1. $\hat{f} = \text{zeta}(f)$, $\hat{g} = \text{zeta}(g)$
2. $\hat{h}(S) = \hat{f}(S) \cdot \hat{g}(S)$ (点ごとの積)
3. $h = \text{mobius}(\hat{h})$

### AND畳み込み

上位集合ゼータ変換を用いて同様に計算できる。

### 包除原理

包除原理を高速に計算するのに利用できる。

## まとめ

| 項目 | 内容 |
|------|------|
| 入力 | 集合関数 $f: 2^U \to \mathbb{R}$ ($|U| = n$) |
| 出力 | ゼータ変換またはメビウス変換の結果 |
| 時間計算量 | $O(2^n \cdot n)$ |
| 空間計算量 | $O(2^n)$ |
| 核心 | 各ビットを順に処理 |
| 応用 | OR/AND 畳み込み、包除原理 |
