## カタラン数とは

カタラン数 $C_n$ は、多くの組合せ問題に現れる重要な数列である。最初のいくつかの値は:

$$
C_0 = 1, \quad C_1 = 1, \quad C_2 = 2, \quad C_3 = 5, \quad C_4 = 14, \quad C_5 = 42, \ldots
$$

## 定義

### 閉じた公式

$$
C_n = \frac{1}{n+1}\binom{2n}{n} = \frac{(2n)!}{(n+1)!\,n!}
$$

### 漸化式

$$
C_0 = 1, \quad C_{n+1} = \sum_{i=0}^{n} C_i \cdot C_{n-i}
$$

この漸化式は、カタラン数の多くの組合せ的解釈に直接対応する。

### 母関数

カタラン数の母関数 $C(x) = \sum_{n=0}^{\infty} C_n x^n$ は次の方程式を満たす:

$$
C(x) = 1 + x \cdot C(x)^2
$$

これを解くと

$$
C(x) = \frac{1 - \sqrt{1 - 4x}}{2x}
$$

## カタラン数が答えになる問題

カタラン数は驚くほど多くの組合せ問題の解として現れる。以下はその代表例である。

### 1. 括弧列の数

$n$ 組の正しい括弧列の数は $C_n$ である。

例えば $n = 3$ のとき: `((()))`, `(()())`, `(())()`, `()(())`, `()()()` の 5 通り。

### 2. 二分木の数

$n$ 個の内部ノードを持つ (根付き) 二分木の数は $C_n$ である。

### 3. 格子経路

$(0,0)$ から $(n,n)$ まで右と上に進む格子経路のうち、対角線 $y = x$ を超えないものの数は $C_n$ である。

### 4. 三角形分割

凸 $(n+2)$ 角形を対角線で三角形に分割する方法の数は $C_n$ である。

## 漸化式の直感的理解

漸化式 $C_{n+1} = \sum_{i=0}^{n} C_i \cdot C_{n-i}$ は括弧列で理解しやすい。

$n+1$ 組の括弧列の最初の `(` に対応する `)` の位置で場合分けする。最初の `(` に対応する `)` が位置 $2i+1$ にあるとき、内側に $i$ 組、外側に $n-i$ 組の括弧列がある。内側の選び方が $C_i$ 通り、外側が $C_{n-i}$ 通りなので、全体は $\sum C_i \cdot C_{n-i}$ 通り。

## 閉じた公式の導出

### 反射原理 (Andre の反射)

$(0,0)$ から $(n,n)$ への格子経路で対角線 $y = x$ を超えないものの数を数える。

全経路数は $\binom{2n}{n}$ である。対角線を超える「悪い経路」の数を引けばよい。

悪い経路は、初めて $y = x + 1$ に到達した点以降を直線 $y = x + 1$ に関して反射すると、$(0,0)$ から $(n-1, n+1)$ への経路と一対一に対応する。よって悪い経路の数は $\binom{2n}{n-1}$ である。

$$
C_n = \binom{2n}{n} - \binom{2n}{n-1} = \frac{1}{n+1}\binom{2n}{n}
$$

## 実装

### 漸化式による $O(n^2)$ 計算

```python title="catalan_dp.py"
def catalan_dp(n: int) -> list[int]:
    c = [0] * (n + 1)
    c[0] = 1
    for i in range(1, n + 1):
        for j in range(i):
            c[i] += c[j] * c[i - 1 - j]
    return c
```

### 閉じた公式による $O(n)$ 計算

```python title="catalan_formula.py"
def catalan(n: int, mod: int = 10**9 + 7) -> int:
    if n == 0:
        return 1
    # C_n = C(2n, n) / (n + 1)
    num = 1
    den = 1
    for i in range(n):
        num = num * (2 * n - i) % mod
        den = den * (i + 1) % mod
    inv_den = pow(den, mod - 2, mod)
    inv_n1 = pow(n + 1, mod - 2, mod)
    return num * inv_den % mod * inv_n1 % mod
```

## 計算量

| 方法 | 時間計算量 | 空間計算量 |
|------|-----------|-----------|
| 漸化式 (DP) | $O(n^2)$ | $O(n)$ |
| 閉じた公式 | $O(n)$ | $O(1)$ |
| 閉じた公式 (mod) | $O(n + \log p)$ | $O(1)$ |

## 漸近的な振る舞い

$$
C_n \sim \frac{4^n}{n^{3/2}\sqrt{\pi}}
$$

カタラン数は $4^n$ のオーダーで増大する。
