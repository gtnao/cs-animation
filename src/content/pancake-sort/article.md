## Pancake Sort とは

Pancake Sort (パンケーキソート) は、**接頭辞反転** (prefix flip) のみを用いて配列を整列するソートアルゴリズムである。パンケーキの積み重ねをフライ返しで並べ替える問題に由来する。

## パンケーキ問題

### 問題設定

$n$ 枚の大きさが異なるパンケーキが積み重なっている。許される操作は、上から $k$ 枚のパンケーキを一度にひっくり返す (接頭辞反転) のみ。最少何回の反転で大きさ順に並べ替えられるか?

この最小回数を**パンケーキ数** $P(n)$ と呼ぶ。

### 既知の結果

$$
\frac{15n}{14} \leq P(n) \leq \frac{5(n+5)}{3}
$$

正確な値は小さな $n$ についてのみ知られている。ちなみにこの問題は、Bill Gates (Microsoft 創業者) が 1979 年に共著論文で上界を改善したことでも知られている。

## アルゴリズムの概要

### 手順

最大値を末尾に移動する Selection Sort 的なアプローチ:

1. 未整列部分 $a[0..k]$ から最大値の位置 $m$ を見つける
2. $a[0..m]$ を反転して最大値を先頭に持ってくる
3. $a[0..k]$ を反転して最大値を位置 $k$ に配置する
4. $k$ を 1 減らして繰り返す

### 具体例

配列 `[3, 1, 5, 2, 4]` をソートする:

1. 最大値 5 は位置 2 → `[5, 1, 3, 2, 4]` → `[4, 2, 3, 1, 5]`
2. 最大値 4 は位置 0 → 既に先頭 → `[1, 3, 2, 4, 5]`
3. 最大値 3 は位置 1 → `[3, 1, 2, 4, 5]` → `[2, 1, 3, 4, 5]`
4. 最大値 2 は位置 0 → 既に先頭 → `[1, 2, 3, 4, 5]`

## 実装

```python title="pancake_sort.py"
def pancake_sort(a: list[int]) -> list[int]:
    n = len(a)
    for size in range(n, 1, -1):
        # Find index of maximum in a[0..size-1]
        max_idx = 0
        for i in range(1, size):
            if a[i] > a[max_idx]:
                max_idx = i

        if max_idx == size - 1:
            continue  # Already in place

        # Flip max to top
        if max_idx != 0:
            a[:max_idx + 1] = a[:max_idx + 1][::-1]

        # Flip max to correct position
        a[:size] = a[:size][::-1]

    return a
```

## 計算量

| ケース | 時間計算量 | 反転回数 |
|--------|-----------|---------|
| 最良 | $O(n)$ | 0 (ソート済み) |
| 平均 | $O(n^2)$ | $O(n)$ |
| 最悪 | $O(n^2)$ | $2(n-1)$ |

**空間計算量:** $O(1)$ (in-place)

最大値探索に $O(n)$、反転操作に $O(n)$、これを $n$ 回繰り返すので $O(n^2)$。

反転回数は最悪 $2(n-1)$ 回 (各反復で最大 2 回の反転) である。

## 安定性

Pancake Sort は**不安定ソート**である。反転操作で等しい要素の相対順序が変わる可能性がある。

## 変種：Burnt Pancake Problem

各パンケーキに「焦げた面」がある場合、大きさ順に並べつつ全ての焦げた面を下にする問題。反転回数の下界は $\frac{3n}{2}$ であることが知られている。

## 特徴と応用

### 長所

- 操作が「接頭辞反転」のみという制約下での解法
- 実装が直感的
- in-place

### 短所

- $O(n^2)$ で実用的ではない
- 不安定ソート

### 応用場面

- 組合せ最適化の理論的研究
- ゲノム再配列問題 (遺伝子の順序変換) への応用
- 計算理論の教育
