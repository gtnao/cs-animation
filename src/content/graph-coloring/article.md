## グラフ彩色とは

**グラフ彩色 (graph coloring)** とは、グラフの頂点に色を割り当てる問題であり、隣接する頂点が同じ色にならないようにする。使用する色数を最小化する問題を**最小彩色問題**と呼ぶ。

### 定義

グラフ $G = (V, E)$ の **$k$-彩色** とは、関数 $c: V \to \{0, 1, \ldots, k-1\}$ であって、全ての辺 $(u, v) \in E$ に対して $c(u) \neq c(v)$ を満たすものである。

グラフ $G$ の**彩色数 (chromatic number)** $\chi(G)$ とは、$G$ が $k$-彩色可能となる最小の $k$ である。

$$
\chi(G) = \min\{\ k \mid G \text{ は } k\text{-彩色可能}\ \}
$$

### 具体例

- 完全グラフ $K_n$: $\chi(K_n) = n$
- 二部グラフ (辺あり): $\chi(G) = 2$
- 木 (辺あり): $\chi(G) = 2$
- 奇数長閉路 $C_{2k+1}$: $\chi(C_{2k+1}) = 3$
- 偶数長閉路 $C_{2k}$: $\chi(C_{2k}) = 2$

## 彩色数の上界

### Brooks の定理

$G$ が完全グラフでも奇数長閉路でもない連結グラフであり、最大次数が $\Delta$ であるとき、

$$
\chi(G) \leq \Delta
$$

完全グラフと奇数長閉路の場合は $\chi(G) = \Delta + 1$ である。

### 貪欲彩色の上界

任意の頂点順序に対して貪欲彩色を行うと、使用色数は高々 $\Delta + 1$ である。

## 貪欲彩色アルゴリズム

### アルゴリズムの概要

1. 頂点を何らかの順序で処理する
2. 各頂点に対して、隣接する頂点が使っていない最小の色番号を割り当てる

### 実装

```python title="greedy_coloring.py"
def greedy_coloring(n: int, adj: list[list[int]]) -> list[int]:
    colors = [-1] * n
    for u in range(n):
        # Collect colors used by neighbors
        used = set()
        for v in adj[u]:
            if colors[v] != -1:
                used.add(colors[v])
        # Assign the smallest available color
        c = 0
        while c in used:
            c += 1
        colors[u] = c
    return colors
```

### 計算量

| 項目 | 計算量 |
|------|--------|
| 時間計算量 | $O(V + E)$ |
| 空間計算量 | $O(V)$ |

### 頂点順序の影響

貪欲彩色の結果は頂点の処理順序に依存する。適切な順序を選べば最適解が得られる場合もあるが、最悪の場合は $\Delta + 1$ 色を使う。

最適な順序の探索は NP 困難であるため、実用的にはヒューリスティックな順序が使われる:

- **次数降順**: 次数の大きい頂点から処理する
- **Welsh-Powell 法**: 次数降順に並べて貪欲に塗る
- **DSatur**: 彩色済み隣接頂点の色数 (飽和度) が最大の頂点を優先する

## 計算困難性

### NP 完全性

$k \geq 3$ に対して、グラフが $k$-彩色可能かの判定は NP 完全問題である。

- 2-彩色: $O(V + E)$ で判定可能 (二部グラフ判定)
- 3-彩色: NP 完全
- $k$-彩色 ($k \geq 3$): NP 完全

したがって、最小彩色数を求める問題は NP 困難である。

### 近似困難性

$P \neq NP$ の仮定の下で、彩色数の定数倍近似も困難であることが知られている。

## 特殊なグラフでの彩色

### 平面グラフ

**四色定理**: 任意の平面グラフは 4 色で彩色可能である。

$$
G \text{ が平面グラフ} \implies \chi(G) \leq 4
$$

5 色で彩色可能であることは比較的簡単に証明できるが (帰納法)、4 色定理の証明はコンピュータ支援が必要だった。

### 区間グラフ

区間グラフの彩色数はクリーク数 (最大クリークのサイズ) に等しく、$O(n \log n)$ で求められる。

## 応用

| 応用 | 説明 |
|------|------|
| レジスタ割り当て | 干渉グラフの彩色 |
| スケジューリング | 競合するタスクに異なる時間枠を割り当て |
| 地図の彩色 | 隣接する領域に異なる色を割り当て |
| 周波数割り当て | 干渉する基地局に異なる周波数を割り当て |

## まとめ

| 項目 | 内容 |
|------|------|
| 入力 | グラフ $G = (V, E)$ |
| 出力 | 各頂点への色の割り当て |
| 貪欲法の計算量 | $O(V + E)$ |
| 最適解の計算量 | NP 困難 |
| 貪欲法の色数上界 | $\Delta + 1$ |
| 応用 | レジスタ割り当て、スケジューリング、周波数割り当て |
