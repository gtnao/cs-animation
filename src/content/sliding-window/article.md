## スライディングウィンドウとは

スライディングウィンドウは、配列上の固定長 (または可変長) のウィンドウを1要素ずつスライドさせ、各位置でのウィンドウ内の統計量を効率的に計算する手法である。

## 固定長ウィンドウ

### 問題

長さ $n$ の配列 $A$ と整数 $k$ が与えられたとき、連続する $k$ 個の要素の和が最大となる区間を求めよ。

### アルゴリズム

最初のウィンドウの和を計算し、以降はスライドごとに追加・削除される要素で差分更新する。

```python title="sliding_window.py"
def max_sum_subarray(a: list[int], k: int) -> int:
    window_sum = sum(a[:k])
    max_sum = window_sum
    for i in range(k, len(a)):
        window_sum += a[i] - a[i - k]
        max_sum = max(max_sum, window_sum)
    return max_sum
```

## 計算量

$$
T(n) = O(n)
$$

初期ウィンドウの計算に $O(k)$、以降の各スライドは $O(1)$ で、合計 $O(n)$。

## 応用

- **移動平均**: 時系列データの平滑化
- **最大/最小部分配列和**: 固定長制約下の最適化
- **文字列のアナグラム検出**: ウィンドウ内の文字頻度を管理

## まとめ

| 項目 | 内容 |
|------|------|
| 入力 | 長さ $n$ の配列、ウィンドウサイズ $k$ |
| 出力 | 各位置でのウィンドウ統計量 |
| 時間計算量 | $O(n)$ |
| 空間計算量 | $O(1)$ (追加) |
