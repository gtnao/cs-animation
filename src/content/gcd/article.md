## ユークリッドの互除法とは

ユークリッドの互除法 (Euclidean algorithm) は、2つの非負整数 $a, b$ の**最大公約数 (Greatest Common Divisor, GCD)** を効率的に求めるアルゴリズムである。紀元前300年頃にユークリッドの『原論』に記載された、最古のアルゴリズムの一つとして知られている。

### 定義

2つの整数 $a, b$ の最大公約数 $\gcd(a, b)$ とは、$a$ と $b$ の両方を割り切る最大の正整数である。慣例として $\gcd(0, 0) = 0$ とする。

$$
\gcd(a, b) = \max\{\ d \in \mathbb{Z}_{>0} \mid d \mid a \text{ かつ } d \mid b\ \}
$$

### 基本性質

ユークリッドの互除法は次の性質に基づく。

$$
\gcd(a, b) = \gcd(b, a \bmod b) \quad (b \neq 0)
$$

この性質と $\gcd(a, 0) = a$ を組み合わせて、再帰的に GCD を計算する。

## アルゴリズム

### 手順

1. $b = 0$ なら $a$ が GCD。終了
2. $a$ を $b$ で割った余り $r = a \bmod b$ を求める
3. $a \leftarrow b$, $b \leftarrow r$ として 1 に戻る

### 具体例

$\gcd(252, 105)$ を計算する。

| ステップ | $a$ | $b$ | $q$ | $r$ | 式 |
|----------|-----|-----|-----|-----|----|
| 1 | 252 | 105 | 2 | 42 | $252 = 105 \times 2 + 42$ |
| 2 | 105 | 42 | 2 | 21 | $105 = 42 \times 2 + 21$ |
| 3 | 42 | 21 | 2 | 0 | $42 = 21 \times 2 + 0$ |

$b = 0$ となったので $\gcd(252, 105) = 21$。

## 正当性の証明

### 補題: $\gcd(a, b) = \gcd(b, a \bmod b)$

**証明:**

$a = bq + r$ ($r = a \bmod b$) とする。

$d$ が $a$ と $b$ の公約数であるとき、$r = a - bq$ より $d$ は $r$ も割り切る。よって $d$ は $b$ と $r$ の公約数でもある。

逆に、$d$ が $b$ と $r$ の公約数であるとき、$a = bq + r$ より $d$ は $a$ も割り切る。よって $d$ は $a$ と $b$ の公約数でもある。

したがって $\{a, b\}$ の公約数の集合と $\{b, r\}$ の公約数の集合は一致し、最大公約数も等しい。 $\square$

### 定理: ユークリッドの互除法は有限ステップで停止し、正しい GCD を返す

**証明:**

**停止性:** 各ステップで $b$ の値は $a \bmod b$ に置き換わる。$0 \leq a \bmod b < b$ なので、$b$ の値は厳密に減少する。$b$ は非負整数なので有限ステップで $b = 0$ に到達する。

**正当性:** 補題より各ステップで $\gcd(a, b)$ の値は保存される。$b = 0$ のとき $\gcd(a, 0) = a$ なので、最後に残った $a$ が元の $\gcd(a, b)$ に等しい。 $\square$

## 計算量

### 定理: ユークリッドの互除法のステップ数は $O(\log(\min(a, b)))$

**証明:**

2回のステップを考える。$a_0, b_0 \to a_1, b_1 \to a_2, b_2$ とすると:

- $a_1 = b_0$, $b_1 = a_0 \bmod b_0$
- $a_2 = b_1 = a_0 \bmod b_0$

$a_0 \bmod b_0 < a_0 / 2$ が成り立つことを示す (場合分け):

- $b_0 \leq a_0 / 2$ のとき: $a_0 \bmod b_0 < b_0 \leq a_0 / 2$
- $b_0 > a_0 / 2$ のとき: $a_0 \bmod b_0 = a_0 - b_0 < a_0 / 2$

したがって $b_2 = a_0 \bmod b_0 < a_0 / 2$。つまり2ステップごとに $b$ の値は半分以下になる。

$b$ の初期値を $B$ とすると、$2k$ ステップ後に $b < B / 2^k$ となる。$b = 0$ に到達するまでのステップ数は高々 $2\lfloor \log_2 B \rfloor + 2 = O(\log B)$。 $\square$

## 実装

### 再帰版

```python title="gcd_recursive.py"
def gcd(a: int, b: int) -> int:
    if b == 0:
        return a
    return gcd(b, a % b)
```

### 反復版

```python title="gcd_iterative.py"
def gcd(a: int, b: int) -> int:
    while b != 0:
        a, b = b, a % b
    return a
```

### C++ 実装

```cpp title="gcd.cpp"
long long gcd(long long a, long long b) {
    while (b) {
        a %= b;
        swap(a, b);
    }
    return a;
}
```

## 応用

### 最小公倍数 (LCM)

最小公倍数は GCD を用いて次のように計算できる。

$$
\text{lcm}(a, b) = \frac{a \cdot b}{\gcd(a, b)}
$$

オーバーフロー対策として $a / \gcd(a, b) \times b$ の順序で計算するとよい。

### 分数の約分

分数 $a/b$ を既約分数にするには、$g = \gcd(a, b)$ で分子・分母を割ればよい。

### 拡張ユークリッドの互除法

ユークリッドの互除法を拡張して、$ax + by = \gcd(a, b)$ を満たす整数 $x, y$ を求めることもできる。これは拡張ユークリッドの互除法として別記事で解説する。
