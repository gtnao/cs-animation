## Manacher's Algorithm とは

Manacher's Algorithm は、文字列の**全ての極大回文部分文字列**を $O(n)$ で求めるアルゴリズムである。1975年に Glenn Manacher によって提案された。

特に、最長回文部分文字列 (Longest Palindromic Substring) を線形時間で求められる。

## 問題設定

文字列 $S = s_0 s_1 \cdots s_{n-1}$ に対して、各位置 $i$ を中心とする最長の回文の半径 $P[i]$ を求める。

## 文字列の変換

奇数長・偶数長の回文を統一的に扱うため、各文字の間にダミー文字 `#` を挿入し、両端に番兵を付加する。

```
"abacaba" → "^#a#b#a#c#a#b#a#$"
```

変換後の文字列 $T$ に対して回文半径を求めれば、元の文字列の奇数長・偶数長の回文がどちらも扱える。

## アルゴリズム

### 核心アイデア

Z-Algorithm と同様に、**過去に計算した回文の情報を再利用する**。

現在判明している最も右まで伸びる回文の中心 $c$ と右端 $r$ を管理する。

### 処理

位置 $i$ を処理するとき:

1. **$i < r$ の場合:** 回文の対称性から、鏡像位置 $\text{mirror} = 2c - i$ の情報を利用。$P[i] = \min(r - i, P[\text{mirror}])$ で初期化
2. **展開:** $T[i - P[i] - 1] = T[i + P[i] + 1]$ である限り $P[i]$ を増やす
3. **$i + P[i] > r$ なら** $c = i, r = i + P[i]$ に更新

### 実装

```python title="manacher.py"
def manacher(s: str) -> list[int]:
    # Transform
    t = "^#" + "#".join(s) + "#$"
    n = len(t)
    p = [0] * n
    c = r = 0

    for i in range(1, n - 1):
        mirror = 2 * c - i
        if i < r:
            p[i] = min(r - i, p[mirror])
        # Expand
        while t[i + p[i] + 1] == t[i - p[i] - 1]:
            p[i] += 1
        # Update center if needed
        if i + p[i] > r:
            c, r = i, i + p[i]

    return p
```

## 計算量の証明

### 命題: Manacher's Algorithm の時間計算量は $O(n)$

**証明:**

while ループの展開が成功するたびに $r$ が増加する。$r$ は単調非減少で最大値は $n$ であるから、while ループの展開成功回数の合計は $O(n)$。

展開失敗は各位置で高々1回なので、合計 $O(n)$。

その他の処理は各位置 $O(1)$ なので、全体 $O(n)$。 $\square$

## 回文半径から回文を取り出す

変換後の回文半径 $P[i]$ から元の文字列での情報を得る。

- 位置 $i$ が元の文字に対応する場合 (奇数長回文): 中心は元の文字列の位置 $(i - 2) / 2$、長さは $P[i]$
- 位置 $i$ が `#` に対応する場合 (偶数長回文): 長さは $P[i]$

最長回文は $P$ 配列の最大値に対応する位置から復元できる。

## 応用

1. **最長回文部分文字列:** $P$ 配列の最大値
2. **全極大回文の列挙:** $P$ 配列から直接得られる
3. **回文の数:** 各位置を中心とする回文の数は $\lceil P[i] / 2 \rceil$ (元の文字列)
4. **回文分割の前処理:** 文字列を最小回数で回文に分割する DP の補助情報

## 具体例

文字列 `abacaba` に対して:

| 元の位置 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---------|---|---|---|---|---|---|---|
| 文字 | a | b | a | c | a | b | a |

変換: `^#a#b#a#c#a#b#a#$`

最長回文は `abacaba` 自体 (中心位置 3、長さ 7)。

## まとめ

| 項目 | 内容 |
|------|------|
| 入力 | 長さ $n$ の文字列 $S$ |
| 出力 | 各位置の回文半径配列 $P$ |

| 空間計算量 | $O(n)$ |
| 核心 | 既知の回文範囲の対称性を利用 |
